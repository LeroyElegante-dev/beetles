# Жуки

Android-игра «Жуки»: нужно ловить насекомых на экране, пока идёт раунд.

## Курсовая работа

- **Вариант 10.** Кастомизация внешнего вида жуков
- **Обязательный объём:** редактор скинов и сохранение наборов

## Как запустить

1. Открыть проект `GameBeetles` в Android Studio (Narwhal / AGP текущего репозитория).
2. Дождаться Gradle Sync.
3. Выбрать устройство или эмулятор с API 24+.
4. Run `app`.

Вкладка **Скины**: выбрать вид (жук / таракан / коровка / золотой), готовую модельку, затем цвета панциря, акцента и глаз, размер и характер. Сохранить набор — он сразу используется на вкладке **Игра**.

## Что сделано в варианте 10

- Редактор встроен в существующую навигацию (вкладка + пункт меню).
- У каждого вида свои готовые модельки (по три): жук, носорог, олень; таракан, гонщик, броня; коровка, сердечко, королева; золотой, скарабей, самоцвет.
- Элементы выбранной модельки можно перекрасить (панцирь, акцент, глаза), изменить размер и характер.
- Выбранный набор хранится в `BeetleSkinStore` и попадает в `GameViewModel` / `GameUiState`.
- `GameFieldView` рисует каждый вид своей моделькой через `BeetleSkinRenderer`.
- Наборы сохраняются в SharedPreferences и переживают перезапуск приложения.
- Автотесты: `BeetleSkinTest`, `BeetleSkinCatalogTest`.

Запуск тестов:

```
./gradlew :app:testDebugUnitTest
```

На Windows:

```
gradlew.bat :app:testDebugUnitTest
```

## Ограничения решения

- Свои картинки загрузить нельзя: модельки рисуются на Canvas, у каждого вида свой силуэт.
- Размер уже появившихся на поле жуков не пересчитывается при смене набора посреди раунда; новые спавны идут с новым масштабом, модельки и цвета обновляются сразу.
- Встроенные наборы («Классический», «Лесная стража», «Ночной кошмар») удалить нельзя.
- Сохранение локальное, без синхронизации между устройствами.
